# My Life in New York (Nokia E71 / E72 Edition) 🗽🎮

An in-browser WebAssembly port of the classic Java ME / J2ME Gameloft game **My Life in New York**, running at native 320x240 Nokia resolution with original graphics, music, and sound.

## 🚀 Play Online
Visit: **[https://gloriakayasa.github.io/accralife/](https://gloriakayasa.github.io/accralife/)**

## 🎮 Controls

### Desktop (Keyboard)
* **Navigate / Move**: Arrow Keys (`↑`, `↓`, `←`, `→`)
* **Action / Select**: `Enter` or `Space`
* **Left Soft Key (Menu / Select)**: `Q` or `F1`
* **Right Soft Key (Back / Cancel)**: `W` or `F2`
* **Phone Keypad**: `0` – `9`
* **Pause / Options**: `Esc`
* **Toggle Keypad**: Click `⌨ Keypad` on top bar
* **Fullscreen**: Click `⛶ Fullscreen` on top bar

### Mobile / Touch
* Full on-screen Nokia tactile keypad with Soft Keys, D-Pad, OK button, and 12-key numeric dialpad.
* Keypad auto-activates on mobile screens or can be toggled anytime.

## 🛠 Tech Stack
* **Java ME Bytecode Runtime**: [FreeJ2ME](https://github.com/hex007/freej2me) + [CheerpJ](https://leaningtech.com/cheerpj/) WebAssembly JVM
* **Sound**: Web Audio API + AudioWorklet + WebGL
* **Hosting**: GitHub Pages
